# Zorionyx — Intelligence That Moves Ideas Forward

A cinematic, responsive React + Vite website for Zorionyx.

## Stack
- React 19 + TypeScript + Vite
- Three.js real-time WebGL hero scene
- Motion-led CSS interactions and responsive layouts
- Vercel-ready SPA routing and SEO assets

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

Vercel settings: Framework **Vite**, Build **npm run build**, Output **dist**.
